RELEASE TARGET

6,150+ bilingual clues

CATEGORY DEPTH

600+ named categories

Each playable category set contains exactly five clues. Category names may recur only with a different validated set.

DIFFICULTY

Two dimensions

The match filters Easy, Medium, or Hard; within that pool, clue tiers 1–5 still rise in difficulty and point value.

Random board selection
  • Choose 12 valid category sets plus one Final clue.
  • No repeated category name within a match.
  • Balance broad subject tags so one board is not dominated by a single topic.
  • Avoid previously seen clues until the eligible pool is exhausted; then prefer least-recently used content.
  • Place one and two Daily Doubles randomly after board selection.
Quality and disputes
  • Every bundled clue requires a source reference and both languages.
  • Validator checks five-clue completeness, duplicates, answer variants, required fields, and translation presence.
  • Time-sensitive facts are excluded or explicitly dated.
  • Host can report and disable a bad clue immediately, then repair it in the editor.
CUSTOM PACKS

The editor shows English and Estonian side by side. CSV import is validated transactionally before anything is saved; invalid rows receive precise errors. English-only custom packs remain usable in English games but are excluded from Estonian selection until translated. CSV export supports backup and sharing.

FAILURE BEHAVIOR

If selected packs cannot supply 12 valid categories and a Final clue at the chosen difficulty/language, setup blocks with the exact shortage. Database upgrades create a backup first; a failed import or migration leaves the previous library unchanged.
